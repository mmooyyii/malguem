## malguem
在Android TV上看 epub / pdf 格式的漫画和小说的app, 让所有的操作都能通过遥控器完成.

支持四种数据源: WebDAV / SMB / OPDS 书库 (Komga、Kavita、Calibre-Web 等自建书库) / 本地硬盘.
添加数据源时可以自动扫描局域网里的 alist(5244) / SMB(445) 服务, 不用对着遥控器敲 IP.

epub 是流式解析的, 只按需拉取文件片段, 开书不用下载整本; pdf 则会整本下载到缓存后按页渲染 (对网盘后端反而更友好).

由于要流式解析epub, 我会**非常频繁**地请求服务器, 如果webdav的后端是网盘, 则有可能触发风控, 尽量用本地磁盘或局域网 NAS 做存储.

### 遥控器操作

- 首页最上面一行是**最近阅读**, 点开直接续读
- 文件列表里对着条目按**菜单键或长按OK**: 书=切换漫画/小说, 数据源=编辑/删除, 最近阅读=切换/移除
- 阅读时按 **OK 键**呼出菜单: 目录跳转 / 跳转到页 / 字号与夜间模式(小说) / 阅读方向与单页模式(漫画) / 切换阅读模式
- 新版本发布后, app 启动时会自动下载并拉起安装
